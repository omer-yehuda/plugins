# The Critics' Table (moved)

The Critics' Table is now a **drill** of **[Army](../army/README.md)**: /army:taste, /army:retaste, /army:menu. Same procedure, same agents, same records folder, and you can run it on its own without raising the army.

```
/plugin install army@omer-plugins
/plugin uninstall critics@omer-plugins
```

This stub only points to the new commands and will be removed in the next release. Docs: [army/docs/drills/critics.md](../army/docs/drills/critics.md).
