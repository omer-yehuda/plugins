# Code Court (moved)

Code Court is now a **drill** of **[Army](../army/README.md)**: /army:trial, /army:appeal, /army:docket. Same procedure, same agents, same records folder, and you can run it on its own without raising the army.

```
/plugin install army@omer-plugins
/plugin uninstall court@omer-plugins
```

This stub only points to the new commands and will be removed in the next release. Docs: [army/docs/drills/court.md](../army/docs/drills/court.md).
