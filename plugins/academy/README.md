# The Academy (moved)

The Academy is now a **drill** of **[Army](../army/README.md)**: /army:enroll, /army:exam, /army:transcript. Same procedure, same agents, same records folder, and you can run it on its own without raising the army.

```
/plugin install army@omer-plugins
/plugin uninstall academy@omer-plugins
```

This stub only points to the new commands and will be removed in the next release. Docs: [army/docs/drills/academy.md](../army/docs/drills/academy.md).
