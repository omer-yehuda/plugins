# Customs (moved)

```
/plugin install skill-installer@omer-plugins
/plugin uninstall customs@omer-plugins
```

This stub only points to the new commands and will be removed in the next release. Scanner docs: [SCANNER.md](../skill-installer/docs/SCANNER.md).
