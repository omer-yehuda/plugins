# ATC (moved)

ATC is now a **drill** of **[Army](../army/README.md)**: /army:claim, /army:clear, /army:radar, /army:release. Same procedure, same agents, same records folder, and you can run it on its own without raising the army.

```
/plugin install army@omer-plugins
/plugin uninstall atc@omer-plugins
```

This stub only points to the new commands and will be removed in the next release. Docs: [army/docs/drills/atc.md](../army/docs/drills/atc.md).
